# Tilago Rebrand

أداة مستقلة جوه After Effects بتبدّل البراند في أي تمبلت (Envato أو غيره)، ومعمولة مخصوص لتمبلتس Element 3D.

## التثبيت (مرة واحدة على كل جهاز)
1. نزّل الـ repo: زرار Code، وبعدين Download ZIP، وفُك الضغط.
2. اقفل After Effects.
3. شغّل `rebrand/install.bat`.
4. افتح After Effects، وبعدين من القايمة: Window > Extensions > Tilago Rebrand.

بعد كده الأداة بتحدّث نفسها لوحدها من GitHub.

## بتعمل إيه
1. **بتفحص البروجكت كله:** أماكن اللوجو، والنصوص، ومشاهد Element 3D وخاماتها.
2. **البراند:** لوجو Tilago واسم TILAGO وخطك وألوانك جاهزين افتراضي، وكلهم يتغيروا.
3. **بتطبّق:**
   - بتبدّل اللوجو في كل مكان بنفس حجم ومكان القديم، وبتعمل Auto Trace لأماكن الـ Masks اللي مربوطة بـ Element 3D، ومن غير ما تكسر الربط.
   - بتبدّل النصوص والخط.
   - **جوه Scene بتاع Element 3D:** بتغيّر ألوان الخامات، وبتحط اللوجو كـ Texture، وبتغيّر صورة البيئة.
4. **الحفظ:** كل ده بيتحفظ في نسخة جديدة باسم `... - Tilago.aep`، وبتتفتح لوحدها. الأصلي مبيتلمسش.
